# VirtuAbogado Frontend

Plataforma legal SaaS que conecta clientes con abogados para la gestión y seguimiento de casos legales en tiempo real.

## Quick Start

```bash
pnpm install
pnpm dev
```

## Features

- Reactividad 100% en Tiempo Real
- Notificaciones Push Transaccionales
- Liquidaciones Automáticas
- Sincronización Admin-Abogado
- Compatibilidad Multiplataforma
- IDs de Expediente Legibles
- Optimizaciones de rendimiento (audio pool, debounce, throttle)
